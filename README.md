# SSC

Public GitHub Pages mirror for SSC (Super Speed Cube).

## Cube preview geometry

The native 2×2 through 4×4 SVG previews use square csTimer-style stickers. Each
face has one continuous black background beneath its stickers; the exposed area
forms the outer frame and internal grid without SVG strokes. Sticker geometry,
the selected 1–4 px line width, face spacing, and absolute SVG origin are snapped
to physical device pixels, while 5×5–7×7 retain the standard SSC SVG profile.
